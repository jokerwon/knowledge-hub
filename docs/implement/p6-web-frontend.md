# P6：Web 前端——单页双栏（可执行计划）

| 项 | 内容 |
| --- | --- |
| 预估 | 14h |
| 前置 | 布局与文档栏（步骤 1~3）：P4 接口可用；流式问答（步骤 4 起）：P5 可用 |
| 被依赖 | P7 验收 |
| 相关决策 | ADR-0018、ADR-0009、ADR-0010 |

## 目标

`apps/web` 单页双栏：左栏文档管理（上传/列表/状态/删除），右栏问答（消息流/引用/输入框）。会话状态仅存页面内存，刷新即清空；不设多页路由。

## 步骤

### 1. 双栏骨架（P6-1，1.5h）

- 单页布局：左侧文档栏、右侧问答主区；样式基线（响应式从简）。
- 验证：浏览器打开布局正确，无路由。

### 2. 上传组件（P6-2，1.5h）

- 文件选择（可加拖拽）；`POST /documents`（multipart）。
- 被拒场景（>2MB、非 MD/TXT）显示服务端返回的明确文案；上传期间有进行中反馈。

### 3. 文档列表（P6-3，2h）

- `GET /documents` 渲染列表（标题/状态/时间）；删除按钮调 `DELETE` 后刷新。
- 上传完成后自动刷新；`failed` 文档可见且可删（呼应"删后重传"）。

### 4. SSE 客户端（P6-4，2h）★ 技术要点

- **`fetch` + `ReadableStream` 手工解析 SSE**：`/chat` 是 POST，浏览器原生 `EventSource` 不可用。
- 按 `@kh/shared` 的 `SseEvent` 联合类型消费事件（类型驱动解析）。
- 验证：对 api 打出的流，解析出 citations/delta/done 三类事件。

### 5. 消息流渲染（P6-5，2.5h）

- `citations` 到达 → 先展示来源文档列表（ADR-0010：引用先于正文）。
- `delta` 逐步追加当前答案；`done` 收尾；`error` 显示错误。

### 6. 多轮历史（P6-6，1h）

- `messages[]` 存页面内存；每次请求全量携带（ADR-0009）；刷新即清空，无需持久化代码。

### 7. 停止与错误（P6-7，1.5h）

- "停止生成"：AbortController 中断 fetch。
- 请求超时/失败：提示用户到左侧文档列表确认状态（ADR-0008 后果）。

### 8. 连通配置（P6-8，0.5h）

- web dev 代理（rewrites 指向 api）或 api 开 CORS，二选一并定死；浏览器无跨域报错。

### 9. 端到端自测（P6-9，1.5h）

- 浏览器走完整闭环（对照总览验收清单 2~6 项）。

## 完成标准

- [ ] 单页双栏，无路由、无持久化会话
- [ ] 上传/列表/删除交互完整，错误文案明确
- [ ] 流式渲染：引用先到、文字流出、可中止
- [ ] 多轮追问有上下文；刷新清空

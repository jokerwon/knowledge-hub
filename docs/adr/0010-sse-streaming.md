# ADR-0010：问答答案 SSE 流式输出

- 状态：已接受
- 日期：2026-08-28

## 背景

LLM 完整生成答案耗时数秒至数十秒，一次性返回会有明显白屏等待。

## 决策

- 问答端点通过 **SSE（Server-Sent Events）** 流式返回，逐 token 呈现。
- 流式事件序列：先发送引用（命中文档列表），再流式发送答案正文，最后发送结束事件；出错发送错误事件。
- 不引入 WebSocket；SSE 单向推送已满足问答场景。

## 后果

- 体验对齐主流 AI 产品；api 需实现 SSE 端点并处理客户端断连，web 需流式渲染与中断处理。
- 引用先于正文到达，前端可在答案生成过程中先行展示来源。

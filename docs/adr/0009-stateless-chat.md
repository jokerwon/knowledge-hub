# ADR-0009：会话不持久化，问答 API 无状态

- 状态：已接受
- 日期：2026-08-28

## 背景

ADR-0001 确定核心闭环含多轮问答。多轮有两种实现：会话/消息入库（可回溯历史），或会话仅存于前端内存。

## 决策

- MVP **不持久化会话**：不建 Conversation / Message 表，刷新页面即清空。
- 问答 API 为**无状态**：多轮所需的对话历史由 web 在每次请求中全量携带，api 不保存任何会话状态。
- 会话持久化列入演进路线，届时补表与会话侧栏，API 契约保持兼容（历史改为服务端装配）。

## 后果

- 数据模型去掉两个聚合，api 无会话管理代码；代价是无法回顾历史问答。
- 随轮次增加，请求体中的历史消息变长，token 消耗上升——单用户本地场景接受。
- 无状态 API 天然支持水平扩展（虽 MVP 用不到）。

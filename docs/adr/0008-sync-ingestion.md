# ADR-0008：同步摄取管线与保护栏

- 状态：已接受
- 日期：2026-08-28

## 背景

单用户本地上传，并发极低。摄取管线可选同步处理、进程内异步+状态机、独立任务队列。

## 决策

- 摄取**同步执行**：上传请求内完成 解析 → 切片 → 向量化 → 落库，响应即最终结果。
- 保护栏：
  - 单文件大小上限 **2MB**；
  - 请求级超时 **60s**；
  - 失败（含超时）将文档标记为 `failed`，支持**删除后重新上传**。
- 文档状态仅需 `ready` / `failed` 两态；不引入异步执行器、任务队列与重试机制。

## 后果

- 无后台任务基础设施，代码路径最短；代价是大文件处理期间请求挂起（已由大小上限与超时封顶）。
- 上传体验依赖 embedding 调用耗时；若未来支持 PDF/大文件，需重新评审并迁移到异步管线。
- 客户端在 60s 超时后应提示用户到文档列表确认状态（服务端可能已完成落库）。

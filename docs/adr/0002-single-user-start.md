# ADR-0002：单用户起步，数据模型预留 user_id

- 状态：已接受
- 日期：2026-08-28

## 背景

用户模型决定认证、数据隔离、租户设计的全部复杂度。MVP 阶段首要目标是验证核心闭环，而非权限体系。

## 决策

- MVP 按**单用户**实现：无注册、无登录、无 JWT、无数据隔离。
- 数据模型在所有者相关的表上**预留 `user_id` 字段**（可空或默认值），保证未来演进为多用户时无需破坏性重建表结构。
- API 不做鉴权中间件，但路由与业务代码不得写死"全局唯一用户"假设（如不允许多处硬编码 user 常量）。

## 后果

- 节省认证/授权/RBAC 的全部实现成本。
- 本地部署形态下单用户是合理默认；若未来对外开放访问，必须先补认证再上线。
- 演进为多用户时的迁移成本被限制在"补认证 + 回填 user_id"范围内。

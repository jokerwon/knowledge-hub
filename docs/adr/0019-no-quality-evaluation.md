# ADR-0019：MVP 不做问答质量系统评估

- 状态：已接受
- 日期：2026-08-28

## 背景

问答质量可选手工冒烟集、自动化 eval、或不评估。第 5 轮决策为不评估。

## 决策

- MVP **不建立任何问答质量评估机制**（无测试集、无 eval 脚本、无打分流程）。
- 验收以**功能验收剧本**（见 design.md）全部走通为准。
- 决策冲突记录：同一轮中确认的剧本草案含"冒烟集人工过"一步，与"不评估"矛盾；以"不评估"为准，该步从剧本删除。

## 后果

- 无质量回归信号，检索/切片参数调整只能靠人肉体感；演进路线中如需调参，应先补评估再调。

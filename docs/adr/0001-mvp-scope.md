# ADR-0001：MVP 核心闭环与范围边界

- 状态：已接受
- 日期：2026-08-28

## 背景

从零启动的知识库项目需要一条不可再砍的最小闭环，防止范围蔓延。

## 决策

MVP 唯一核心闭环：**上传文档 → 向量化 → 基于文档的多轮问答（带引用）**。

配套边界：

- 文档管理仅含最小必要能力：列表、删除；不做在线编辑、不做版本管理。
- 文档格式仅接受 **Markdown / TXT**，PDF/DOCX/OCR/网页剪藏全部移出 MVP。
- 明确不做（Out of Scope）：知识图谱、审核工作流、协作分享、多格式解析、OCR、评估平台。

## 后果

- 摄取管线无需引入重型解析器，切片策略只需覆盖纯文本。
- 所有后续设计决策若不能服务核心闭环，默认拒绝。
- 被砍掉的能力在演进路线中保留位置，但当前不写一行代码。

# ADR-0006：检索策略——纯向量 topK

- 状态：已接受
- 日期：2026-08-28

## 背景

检索策略可选纯向量、混合检索（向量+全文）、混合+重排，逐级效果增强但链路复杂度与索引维护成本同步上升。

## 决策

- MVP 仅实现**纯向量检索**：查询向量化后与切片向量做余弦相似度 topK。
- 不建全文/BM25 索引，不引入重排模型。
- 检索结果直接作为问答上下文，命中切片即引用来源。
- topK 值与相似度阈值设为可调配置，默认 topK=5。

## 后果

- 系统内只有一份向量索引（pgvector），无第二套索引的同步与融合问题。
- 中文专有名词、精确代号类查询的命中质量已知偏弱，属接受范围；未来可按需叠加全文检索（届时单独立 ADR）。

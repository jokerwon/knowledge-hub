# ADR-0012：切片策略——递归字符切分

- 状态：已接受
- 日期：2026-08-28

## 背景

MD/TXT 语料可选固定长度切分、按 Markdown 标题结构切分、递归字符切分。

## 决策

- 使用 LangChain **RecursiveCharacterTextSplitter**，分隔符优先 Markdown 结构符号（标题、段落、换行）再退化为字符。
- 目标切片大小 **~500 字符**，重叠 **~50 字符**；两个参数走配置可调。
- 切片保留在文档内的序号（seq），不做标题路径等富元数据。

## 后果

- 纯文本语料的标准解法，语义切断风险低于固定长度，实现成本低于结构化解折。
- 切片参数调整只影响新摄取的文档，已有文档不回溯重建（需重建时删除重传）。

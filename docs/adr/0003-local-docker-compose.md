# ADR-0003：本地 docker-compose 单形态部署

- 状态：已接受（「全部依赖」范围由 ADR-0017 修订为仅基础设施）
- 日期：2026-08-28

## 背景

部署形态决定中间件取舍：单机自用场景下，能用进程内/单机方案就不引入分布式组件。

## 决策

- 唯一目标部署形态：**本地 `docker-compose` 一条命令拉起全部依赖**。
- 不追求高可用、横向扩容、HTTPS、备份策略等云端能力。
- 中间件选型须满足"单机可跑、资源占用克制"；重型组件（如独立消息队列集群、多副本搜索引擎）需要额外论证才能引入。

## 后果

- 依赖清单倾向于少而精，能用 PostgreSQL 解决的不再引入第二个存储。
- 云端部署能力明确放弃，未来需要时作为新决策重新评审。
- 开发者本机即完整环境，调试链路最短。
